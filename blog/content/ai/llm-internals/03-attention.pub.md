01편에서는 "고양이"라는 토큰이 Embedding Matrix에서 `[0.2, 0.1]` 같은 벡터를
가져오는 것까지 봤습니다. 그런데 이 벡터를 그대로 쓰지는 않습니다. Transformer를
통과하면서 이 벡터는 계속 변합니다. 이번 편에서 볼 **Attention**이 그 변화의
첫 단계입니다.

## 1. 같은 단어인데 뜻이 다르다

이런 두 문장을 봅시다.

```text
나는 은행에 갔다.
나는 강가의 은행을 봤다.
```

"은행"이라는 같은 토큰인데 하나는 금융기관, 하나는 강둑입니다. 그런데 지금까지 본
Embedding Matrix는 "은행"이라는 토큰에 대해 **딱 하나의 벡터**만 갖고 있습니다.
두 문장의 "은행"은 시작할 때는 완전히 같은 벡터에서 출발합니다.

- **Embedding** — "이 토큰이 일반적으로 어떤 패턴과 관련되어 있는가?"
- **Attention** — "지금 이 문장에서 다른 토큰들과 어떤 관계가 있는가?"

Attention을 거치고 나면, 같은 "은행"이라도 주변에 "갔다"가 있느냐 "강가"가
있느냐에 따라 **서로 다른 벡터**로 갈라집니다. Embedding이 사전적 의미의 출발점을
주는 자리라면, Attention은 그 단어가 지금 이 문장에서 어떤 뜻으로 쓰였는지를
결정하는 자리입니다.

## 2. 고양이가 생선을 먹었다

우리 장난감 모델의 문장으로 봅시다.

```text
고양이가 생선을 먹었다.
```

처음의 "고양이"는 단순히 `Embedding("고양이") = [0.2, 0.1]`이었습니다. 그런데
Attention을 거치면서

```text
고양이 → 생선과의 관계 → 먹었다와의 관계 → 문맥을 반영한 새로운 벡터
```

가 됩니다. **"주변 단어를 살펴보고, 그 정보를 섞어서 지금 이 자리에 맞는 새 벡터를
만드는 것"** 이 Attention이 하는 일의 전부입니다.

## 3. Query, Key, Value

Attention은 토큰 벡터 하나를 세 가지 역할로 나눠서 씁니다. 도서관에서 책을 찾는
상황에 비유하면 이해하기 쉽습니다.

| 이름 | 역할 | 비유 |
|------|------|------|
| Query ($Q$) | "나는 지금 무엇을 찾고 있는가" | 내가 사서에게 하는 질문 |
| Key ($K$) | "나는 이런 정보를 갖고 있다" | 책마다 붙은 색인 카드 |
| Value ($V$) | "실제로 건네줄 내용물" | 색인 카드 뒤에 있는 책 본문 |

각 토큰은 자신의 임베딩 $X$를 세 개의 학습 가능한 행렬 $W_q, W_k, W_v$에 통과시켜
$Q = XW_q$, $K = XW_k$, $V = XW_v$를 얻습니다. $W_q, W_k, W_v$는 02편에서 본
Embedding과 똑같은 방식으로, 역전파를 거치며 학습되는 숫자들입니다.

계산 부담을 줄이기 위해 이번 예제에서는 $W_q, W_k, W_v$를 전부 항등행렬(곱해도
바뀌지 않는 행렬)이라고 두겠습니다. 즉 $Q = K = V = X$이고, 01편의 임베딩을 그대로
씁니다.

```text
고양이 → [0.2, 0.1]
강아지 → [0.1, 0.3]
생선   → [0.4, 0.2]
```

## 4. "고양이"가 무엇에 주목하는지 계산해 보자

"고양이"의 Query와 세 토큰의 Key를 내적합니다.

```text
q·k(고양이) = 0.2×0.2 + 0.1×0.1 = 0.05
q·k(강아지) = 0.2×0.1 + 0.1×0.3 = 0.05
q·k(생선)   = 0.2×0.4 + 0.1×0.2 = 0.10
```

값이 클수록 "더 많이 참고하겠다"는 뜻입니다. 지금은 생선 쪽 점수가 살짝 더
높습니다.

## 5. 점수를 나누고 나서 Softmax

실제 Transformer는 이 점수를 그대로 쓰지 않고, Key 벡터의 차원 수 $d_k$의 제곱근으로
나눈 뒤에 Softmax를 적용합니다.

$$
\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

여기서는 $d_k = 2$이므로 $\sqrt{d_k} \approx 1.41$로 나눕니다.

```text
0.05 / 1.41 ≈ 0.035
0.05 / 1.41 ≈ 0.035
0.10 / 1.41 ≈ 0.071
```

이 값을 Softmax에 넣으면 대략 이런 확률이 나옵니다.

```text
고양이 → 32.9%
강아지 → 32.9%
생선   → 34.1%
```

이 비율로 Value(=$X$)를 가중합하면, "고양이"의 새 표현은 대략

```text
0.329×[0.2,0.1] + 0.329×[0.1,0.3] + 0.341×[0.4,0.2] ≈ [0.235, 0.200]
```

가 됩니다. 원래 `[0.2, 0.1]`이었던 "고양이"가, 세 토큰의 정보가 섞인 `[0.235,
0.200]`으로 바뀌었습니다. 이게 바로 "생선과의 관계, 먹었다와의 관계"가 벡터에
반영되는 방식입니다.

**왜 굳이 $\sqrt{d_k}$로 나눌까요.** 벡터 차원이 커질수록 내적 값이 아주 커지거나
작아질 수 있습니다. 값이 극단적이면 Softmax 결과가 한쪽으로 완전히 쏠려서(한
토큰이 100%, 나머지가 0%) 02편에서 본 Gradient가 거의 0이 되어 학습이 멈춥니다.
$\sqrt{d_k}$로 나누는 건 내적 값의 크기를 적당한 범위로 되돌려서, 학습 신호가 계속
흐르게 하는 장치입니다.

## 6. 한 명이 아니라 여러 명에게 물어본다: Multi-Head

지금까지는 $W_q, W_k, W_v$ 한 세트로 Attention을 한 번만 계산했습니다. 실제
Transformer는 더 작은 $W_q, W_k, W_v$ 세트를 여러 개(보통 8개, 16개 등, 이를
"헤드"라고 부릅니다) 두고, 각자 독립적으로 위 계산을 한 뒤 결과를 이어 붙입니다.

```text
head_1 = Attention(XW_q¹, XW_k¹, XW_v¹)
head_2 = Attention(XW_q², XW_k², XW_v²)
...
MultiHead(X) = Concat(head_1, ..., head_h) × W_o
```

한 사람에게만 "이 상황을 어떻게 봐야 해?"라고 묻는 대신, 관점이 다른 여러 사람에게
동시에 묻고 의견을 종합하는 것과 비슷합니다. 한 헤드는 주어-동사 관계에, 다른
헤드는 바로 앞 단어와의 관계에, 또 다른 헤드는 문장 저 멀리 있는 단어와의 관계에
더 잘 반응하는 식으로 역할이 자연스럽게 나뉘는 경향이 관찰됩니다.

## 7. 미래는 못 본다: Causal Mask

ChatGPT는 다음 토큰을 예측하며 문장을 한 칸씩 이어 쓰는 방식으로 동작합니다.
그러려면 "고양이가 생선을"까지 보고 "먹었다"를 예측하는 연습을 할 때, 아직 나오지
않은 미래 토큰을 미리 들여다보면 안 됩니다. 그래서 Attention 점수를 계산할 때
미래 위치에 해당하는 칸을 $-\infty$로 채운 뒤 Softmax를 적용합니다.

```text
          고양이   생선    먹었다
고양이  [  0.1,   -inf,   -inf ]
생선    [  0.3,    0.4,   -inf ]
먹었다  [  0.2,    0.5,    0.3 ]
```

$-\infty$는 Softmax를 통과하면 확률 0이 됩니다. 그 결과 "고양이" 자리는 자기
자신만, "생선" 자리는 "고양이"와 "생선"까지만, "먹었다" 자리는 셋 다 참고할 수
있습니다. 대각선 아래쪽만 보이는 이 삼각형 형태를 **Causal Mask**라고 부릅니다.

## 정리

Attention을 한 문장으로 요약하면 이렇습니다.

> 각 토큰이 "나는 지금 무엇이 궁금한가(Query)"를 던지고, 다른 모든 토큰의 "나는
> 이런 정보를 갖고 있다(Key)"와 비교해서, 관련이 높은 토큰의 "실제 내용(Value)"을
> 많이 섞어 새로운 벡터를 만든다. 단, 미래 토큰은 미리 볼 수 없고(Causal Mask),
> 이 과정을 여러 관점(Multi-Head)에서 동시에 한다.

그런데 정보를 모았다고 끝이 아닙니다. "고양이"가 생선·먹었다와의 관계 정보를
가져왔다면, 그다음엔 "이 정보를 가지고 뭘 하지?"가 필요합니다. 다음 편에서 볼
**Feed Forward Network(FFN)** 가 그 역할을 맡습니다.
