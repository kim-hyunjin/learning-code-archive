지난 편에서 "고양이"의 임베딩이 `[0.2, 0.1]`에서 `[0.24, 0.16]`으로 바뀌는 걸
봤습니다. 그런데 그 Gradient `[-0.4, -0.6]`이 어디서 나온 숫자인지는 그냥
주어진 것으로 넘어갔습니다. 이번 편에서는 그 숫자가 정확히 어떻게 계산되는지,
"틀린 정도를 계산하고 → 어떤 숫자를 바꿀지 알아내고 → 숫자를 조금씩 바꾸는" 전체
과정을 처음부터 수학을 어렵게 만들지 않고 연결해 봅니다.

## 1. 먼저 전체 그림

우리가 궁금한 건 이겁니다.

```text
고양이 → 벡터 → 예측 → "생선일 것 같다!" → 정답과 비교
→ 틀린 정도(Loss) → 어떤 숫자를 바꿔야 할까? → Gradient
→ 숫자들을 조금 수정 → 다시 예측
```

여기서 각 개념의 역할을 미리 한 줄로 잡아 두면 이렇습니다.

| 개념 | 쉽게 말하면 |
|------|-------------|
| 미분 | 어떤 숫자를 조금 바꾸면 결과가 얼마나 변하는지 측정 |
| Gradient | 모든 숫자를 어느 방향으로 얼마나 바꿔야 Loss가 줄어드는지 알려주는 정보 |
| 역전파 | 최종 Loss에서 출발해서 앞쪽의 숫자들까지 Gradient를 전달하는 과정 |
| Gradient Descent | Gradient를 이용해서 실제 숫자를 조금씩 수정하는 방법 |

이제 하나씩 봅니다.

## 2. 먼저 "미분"부터

미분은 어렵게 생각할 필요가 없습니다. 어떤 숫자 $x$가 있고 결과가 $y = x^2$라고
해 봅시다.

```text
x = 2    → y = 4
x = 2.01 → y ≈ 4.0401
```

$x$를 아주 조금 증가시켰더니 $y$도 증가했습니다. 미분은 바로 이런 것을 알아내는
것입니다. **"$x$를 아주 조금 움직이면 $y$가 얼마나 움직이는가?"**

## 3. LLM에서는 무엇을 미분하나

LLM에서는 $y$가 단순한 숫자가 아니라 **Loss**입니다.

```text
모델의 어떤 숫자 = x
x를 조금 바꾸면 → 모델의 예측이 달라지고 → Loss도 달라진다
```

우리가 알고 싶은 건 "이 숫자를 조금 올리면 Loss가 커질까, 작아질까?"입니다.

- $x$를 조금 올렸더니 Loss가 **증가**했다 → "이 숫자를 올리면 안 되겠구나"
- $x$를 조금 올렸더니 Loss가 **감소**했다 → "이 숫자를 올리는 방향이 좋겠구나"

이 방향과 민감도를 알려주는 것이 미분입니다.

## 4. 그런데 LLM에는 숫자가 엄청 많다

실제 LLM에는 Embedding, Attention, FFN 등에 수십억 개 이상의 숫자가 있을 수
있습니다. 각각을 $w_1, w_2, w_3, \ldots, w_n$이라 하고 Loss를 $L$이라 하면, 모델은
각각에 대해

$$
\frac{\partial L}{\partial w_1},\ \frac{\partial L}{\partial w_2},\ \ldots,\ \frac{\partial L}{\partial w_n}
$$

을 계산합니다. 이 값들 하나하나가 "이 숫자를 조금 바꾸면 Loss가 얼마나
변하는가"를 뜻합니다. 이걸 전부 모으면 **Gradient**입니다.

```text
w1 → 0.8
w2 → -0.3
w3 → 0.1
w4 → -1.2

Gradient = [0.8, -0.3, 0.1, -1.2]
```

Gradient는 그냥 "각 숫자를 어느 방향으로 바꾸면 Loss가 줄어드는지에 대한 지도"라고
생각하면 됩니다.

## 5. 왜 "역전파"가 필요한가

LLM의 구조를 아주 단순하게 그리면 이렇습니다.

```text
입력 → Embedding → Attention → FFN → 예측 → Loss
```

Loss가 나왔는데 우리가 바꾸고 싶은 건 Embedding의 숫자입니다. 그런데 Loss 바로
앞에는 FFN이, 그 앞에는 Attention이, 그 앞에는 Embedding이 있습니다. **"Loss가
Embedding의 첫 번째 숫자에 얼마나 영향을 받았는지"** 를 어떻게 알아낼까요.

순방향 계산은 `Embedding → Attention → FFN → Loss` 순서였지만, Gradient를 계산할
때는 반대로 `Loss → FFN → Attention → Embedding` 방향으로 거꾸로 계산합니다.
그래서 **역전파(Backpropagation)** 라고 부릅니다.

## 6. 아주 간단한 예로 계산해 보자

어떤 모델이 이렇게 계산한다고 합시다.

```text
x → y = 2x → Loss = y²
```

$x = 3$일 때 순방향 계산은 이렇습니다.

```text
x = 3
y = 2 × 3 = 6
Loss = 6² = 36
```

이제 역전파를 합니다. 우리는 "$x$를 조금 바꾸면 Loss가 어떻게 변하는가"를
알고 싶습니다. 계산을 거꾸로 따라갑니다.

$$
\text{Loss} = y^2 \ \Rightarrow\ \frac{d\,\text{Loss}}{dy} = 2y = 2 \times 6 = 12
$$

$$
y = 2x \ \Rightarrow\ \frac{dy}{dx} = 2
$$

체인 룰(연쇄 법칙)로 두 미분을 곱하면,

$$
\frac{d\,\text{Loss}}{dx} = \frac{d\,\text{Loss}}{dy} \times \frac{dy}{dx} = 12 \times 2 = 24
$$

즉 **Gradient = 24**라는 걸 알아냈습니다.

## 7. Gradient Descent

Gradient가 24라는 건, 대략 "지금 $x$를 증가시키는 방향으로 가면 Loss가
증가한다"는 뜻입니다. 그러니 우리는 $x$를 반대 방향으로 움직여야 합니다. 이 방법이
**Gradient Descent(경사 하강법)** 입니다.

$$
\text{새 값} = \text{기존 값} - \text{학습률} \times \text{Gradient}
$$

학습률을 0.1이라고 하면,

```text
새로운 x = 3 - 0.1 × 24 = 0.6
```

$x$가 3에서 0.6으로 바뀝니다.

## 8. 다시 계산해 보자

$x = 0.6$이면

```text
y = 2 × 0.6 = 1.2
Loss = 1.2² = 1.44
```

아까는 Loss가 36이었는데, 1.44로 크게 줄었습니다. **학습이 된 것**입니다.

## 9. LLM에서도 똑같은 일이 벌어진다

지난 편의 "고양이가 생선을" 예측으로 돌아가 봅시다. 예측이

```text
생선 30%   (실제 정답은 생선)
```

이었고 Loss가 나왔습니다. 역전파가 시작됩니다.

```text
Loss → LM Head → Transformer Layer N → ... → Attention → Embedding
```

각 단계에서 "이전 단계의 숫자가 최종 Loss에 얼마나 영향을 줬는가"를 계산합니다.
그 결과 Embedding의 각 숫자에 대해

```text
0.2 → Gradient = -0.7
0.1 → Gradient = 0.3
```

같은 정보가 나온다고 해 봅시다. 학습률이 0.01이라면,

```text
0.2 - 0.01 × (-0.7) = 0.207
0.1 - 0.01 ×   0.3  = 0.097
```

```text
학습 전  고양이 → [0.200, 0.100]
학습 후  고양이 → [0.207, 0.097]
```

지난 편에서 학습률 0.1로 계산했던 것보다 훨씬 작게 바뀌었습니다. 학습률이 작을수록
한 번에 바뀌는 양이 작아진다는 것도 함께 기억해 두면 좋습니다.

## 10. 이걸 엄청나게 반복한다

한 번 바뀐다고 의미가 생기는 게 아닙니다.

```text
① 입력 → ② 예측 → ③ 정답과 비교 → ④ Loss
→ ⑤ 역전파 → ⑥ Gradient 계산 → ⑦ Gradient Descent → ⑧ 가중치 수정
```

을 문장 하나마다 반복하고, 다음 문장에 대해 다시 반복합니다. 이걸 수십억~수조 개
토큰에 대해 되풀이하는 것이 "LLM을 학습시킨다"는 말의 실체입니다.

## 11. 여기서 한 가지 더: Q/K/V도 같이 학습된다

다음 편부터 볼 Attention에는 $W_q$, $W_k$, $W_v$라는 가중치가 등장합니다. 이것도
처음에는 랜덤한 숫자이고, 지금까지 본 것과 똑같은 방식으로 학습됩니다.

```text
예측 오류 → Loss → 역전파 → Wq 수정, Wk 수정, Wv 수정, Embedding 수정, FFN 수정, ...
```

즉 "어떤 단어를 서로 관련 있다고 판단해야 하는가"를 결정하는 방식도 사람이 정해준
규칙이 아니라, 학습을 통해 만들어집니다.

## 정리

각 개념을 한 문장으로 다시 정리하면 이렇습니다.

- **미분** — "이 숫자를 조금 움직이면 Loss가 얼마나 변하지?"
- **Gradient** — "각 숫자를 어느 방향으로 움직여야 Loss가 줄어들지?"
- **역전파** — "최종 Loss에서부터 거꾸로 계산해서 각 숫자의 Gradient를 어떻게 구하지?"
- **Gradient Descent** — "구한 Gradient를 이용해서 실제 숫자를 어떻게 수정하지?"

여기까지 이해하면 "AI가 학습한다"는 말의 실체가 꽤 단순해집니다.

```text
예측 → 틀린 정도 계산 → 미분해서 책임 소재 계산 → 숫자 수정 → 반복
```

이걸 수십억 개의 파라미터에 대해 엄청난 횟수로 반복하는 것이 LLM 학습의 핵심입니다.

다음 편에서는 지금까지 "예측기"라고 뭉뚱그려 뒀던 부분을 뜯어서, 실제 Transformer가
문맥을 읽을 때 쓰는 **Attention**이 정확히 무엇을 계산하는지 봅니다.
