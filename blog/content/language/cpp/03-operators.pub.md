C++의 연산자 자체는 다른 C 계열 언어와 크게 다르지 않지만, 정수 나눗셈이나 증감 연산자처럼 "동작은 알지만 왜 그런지는 설명하기 어려운" 지점이 몇 군데 있습니다. 이 글에서는 그런 지점들을 코드로 짚어봅니다.

## 산술 연산자

```cpp
int a = 7, b = 2;
std::cout << a + b << "\n"; // 9
std::cout << a - b << "\n"; // 5
std::cout << a * b << "\n"; // 14
std::cout << a / b << "\n"; // 3  (정수 나눗셈: 소수점 버림)
std::cout << a % b << "\n"; // 1  (나머지)
```

정수끼리 나누면 결과도 정수입니다. `7 / 2`가 `3.5`가 아니라 `3`이 나오는 건 오류가 아니라 C++의 정수 나눗셈 규칙입니다. 실수 결과가 필요하면 피연산자 중 하나 이상을 실수로 만들어야 합니다.

```cpp
double result = a / static_cast<double>(b); // 3.5
```

## 대입 연산자

```cpp
int x = 10;
x += 5;  // x = x + 5
x -= 3;  // x = x - 3
x *= 2;  // x = x * 2
x /= 4;  // x = x / 4
```

복합 대입 연산자는 단순 축약 표기가 아니라, 왼쪽 값을 한 번만 평가한다는 점에서 `x = x + 5`와 미묘하게 다를 수 있습니다(예: `arr[i++] += 1`처럼 부수 효과가 있는 인덱스 표현식일 때).

## 관계 연산자와 논리 연산자

```cpp
int a = 5, b = 10;
bool isEqual = (a == b);       // false
bool isGreater = (a > b);      // false
bool isLessOrEqual = (a <= b); // true

bool result = (a < b) && (b < 20); // 논리 AND: 둘 다 참이어야 참
bool anyTrue = (a > b) || (b > 5); // 논리 OR: 하나만 참이어도 참
bool negate = !(a == b);           // 논리 NOT
```

`&&`와 `||`는 **단락 평가(short-circuit evaluation)**를 합니다. `&&`의 왼쪽이 거짓이면 오른쪽은 아예 평가하지 않고, `||`의 왼쪽이 참이면 오른쪽을 평가하지 않습니다. 이 특성을 이용해 안전성 검사를 앞에 두는 패턴이 흔합니다.

```cpp
int* ptr = nullptr;
if (ptr != nullptr && *ptr > 0) {
    // ptr이 nullptr이면 *ptr은 절대 평가되지 않으므로 안전
}
```

## 증감 연산자: 전위 vs 후위

```cpp
int i = 5;
int a = ++i; // 전위: 먼저 증가시킨 뒤 값을 반환 → i=6, a=6
int j = 5;
int b = j++; // 후위: 먼저 값을 반환한 뒤 증가시킴 → j=6, b=5
```

두 방식 모두 `i`(혹은 `j`)를 1 증가시키지만, **식의 값으로 무엇을 돌려주느냐**가 다릅니다. 반복문의 증감식(`for (...; ...; i++)`)처럼 결과값을 쓰지 않는 자리에서는 어느 쪽을 써도 동작이 같지만, 관례적으로 전위(`++i`)를 기본으로 사용합니다. 클래스 타입(예: 반복자)에서는 후위 증가가 내부적으로 임시 복사본을 만들기 때문에 비용 차이가 날 수 있습니다.

## 혼합 표현식에서 흔한 실수

```cpp
int a = 5;
int b = 2;
double avg = (a + b) / 2;        // 정수 나눗셈이라 3.0이 됨 (의도는 3.5였을 수 있음)
double avgFixed = (a + b) / 2.0; // 2.0으로 바꾸면 실수 나눗셈이 되어 3.5
```

대입과 비교를 헷갈리는 것도 자주 나오는 실수입니다.

```cpp
int a = 5;
if (a = 10) { // '=='가 아니라 '='를 써서, a에 10을 대입하고 그 결과(10, 즉 참)로 조건을 판단
    std::cout << "항상 실행됨\n";
}
```

많은 컴파일러가 이런 코드에 경고를 띄워주지만, 경고를 무시하면 의도와 다르게 항상 참이 되는 조건문이 생길 수 있습니다. 비교 의도라면 `if (a == 10)`으로 써야 합니다.
